How to read this

A ribbon’s thickness is the same everywhere it goes — one global scale — so the flow you see leaving a column is the flow that genuinely continues. Where a column’s stack is shorter than the one before it, that difference is material whose lineage stops at that rank (the taxonomy fills Species for roughly a fifth of living labels), not material that was dropped.

Merging. The threshold is applied column by column, left to right: any class carrying less than the threshold is pooled into that column’s grey Other node and its ribbon ends there. Pooling one column changes what is left for the next, so the sweep re-measures at every column. Nothing is discarded — the pooled total is exactly the sum of what went into it.

Converging flow. A node is identified by its column and its value, so the same taxon reached from several datasets is one node, and the ribbons visibly merge into it. Node and link values are re-derived from surviving ribbons on every change, so the diagram conserves flow at each node by construction.
